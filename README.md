# TIL
Git Bash에서의 명령어

whoami : 사용자 이름 확인
pwd(print working directory) : 현재 디렉토리 위치 확인
ls (list의 약자) : 폴더 안 내용물 확인
clear : 현재 터미널 지우고 맨 위 커서 이동
ls -al : a는 all l은 list - 리스트 안에 상세 표시를 해주라
ls -alh : h는 휴먼리더블(사람이 읽기 편하게 용량 단위까지 나오는 상세 표시)
읽을 때 앞에 D는 디렉토리
l은 link
rwx : r은 소유자접근권한(쓰기권한) read  write 읽기권한  execute 실행권한
. 하나는 현재 디렉토리를 의미
.. 은 상위 디렉토리를 의미
mkdir : make Directory 폴더를 만든다  mkdir 폴더명   
입력 후 ls로 확인하면 kant가 만들어진 걸 볼 수 있다
